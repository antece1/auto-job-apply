## Fit check (skip jobs that match any rule)

- Maximum years of experience **required**: 2 ("preferred" is fine)
- Skip titles containing: Senior, Sr., Staff, Principal, Lead, Manager, Director, or level III and above
- Skip jobs that require: U.S. citizenship or a security clearance (edit to match your work authorization)
- Acceptable degrees when a posting names a specific one: ASK (for example "Mechanical Engineering, Electrical Engineering, or related field")
- Maximum posting age: 21 days
- Maximum submitted applications per employer without a referral: 2

## Standard answers

- Expected pay: give one number about a third of the way up the posted range, never the floor and never above the midpoint. Examples: $90,000-$120,000 → $100,000; $25-$38/hr → $29.50/hr. Hourly roles get an hourly number (annual ÷ 2,080). No posted range: ASK. If a form insists on a range, enter that number to the posted midpoint.

- Unknown questions: ask (the agent collects questions the profile doesn't answer and asks you all at once). Change to "pick" to let the agent choose a sensible answer itself and list it in the summary; it still never invents skills or experience.
- Sign in with Google: No. Change to "Yes, account: you@example.com" to let the agent click "Sign in with Google" and pick that account. The agent never types a password or verification code.
- Postings folder: none. Set a folder path to have the agent save a JD.md summary of every posting it applies to.
